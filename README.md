# NASA Mission Intelligence: RAG Chat with Live Evaluation

A chat assistant that answers questions about the Apollo 11, Apollo 13 and Challenger missions from 12 mission
transcripts and reports. It cites its sources, says when the documents don't cover a question, and scores every
answer live for faithfulness and relevance with RAGAS.

Python · OpenAI · ChromaDB · RAGAS · Streamlit
